# חיבור האתר ל-Google Sheets

כל פעולה באתר (הרשמה, עדכון יעד, הפקדה, התנתקות) תיכתב כשורה חדשה בגיליון.
**בלי שרת, בלי תשלום, בלי הרשמה לשום שירות** — רק חשבון גוגל רגיל.

לוקח בערך 10 דקות. אחרי שגומרים, זה עובד לבד.

---

## שלב 1 — יוצרים גיליון

1. נכנסים ל-[sheets.new](https://sheets.new) (זה פותח גיליון חדש וריק).
2. נותנים לו שם למעלה, למשל **SmartSaver AI — נתונים**.

לא צריך ליצור עמודות או כותרות. הסקריפט יוצר הכל לבד בפעם הראשונה.

## שלב 2 — פותחים את עורך הסקריפטים

בתוך הגיליון: **תוספים** (Extensions) ← **Apps Script**.

נפתחת לשונית חדשה עם קובץ בשם `Code.gs` שיש בו כמה שורות ריקות.

## שלב 3 — מדביקים את הקוד

1. **מוחקים את כל מה שכתוב שם** (Ctrl+A ואז Delete).
2. פותחים את הקובץ [`Code.gs`](Code.gs) שנמצא בתיקייה הזו, מעתיקים את **כולו**, ומדביקים.
3. שומרים: **Ctrl+S**.

## שלב 4 — בדיקה שהכתיבה עובדת (לפני שנוגעים באתר)

בסרגל שמעל הקוד יש רשימה נפתחת של פונקציות. בוחרים **`testWrite`** ולוחצים **Run**.

בפעם הראשונה גוגל יבקש הרשאה:

| מה מופיע | מה ללחוץ |
|---|---|
| "Authorization required" | **Review permissions** |
| בחירת חשבון | החשבון שלך |
| "Google hasn't verified this app" | **Advanced** ← **Go to … (unsafe)** |
| רשימת הרשאות | **Allow** |

> ה"unsafe" הזה נראה מפחיד אבל הוא סטנדרטי — גוגל מציג אותו לכל סקריפט
> שכתבת בעצמך ולא שלחת לאישור רשמי. אתה מאשר לקוד שלך לגשת לגיליון שלך.

חוזרים לגיליון. אמורה להופיע לשונית חדשה בשם **Log** עם שורת כותרות כחולה
ושורת בדיקה אחת. **אם זה קרה — החלק הקשה נגמר.** אפשר למחוק את שורת הבדיקה.

## שלב 5 — מפרסמים ככתובת אינטרנט

בעורך הסקריפטים: **Deploy** ← **New deployment**.

1. ליד "Select type" לוחצים על גלגל השיניים ← **Web app**.
2. ממלאים:

   | שדה | מה לבחור |
   |---|---|
   | Description | `SmartSaver` (לא חשוב) |
   | **Execute as** | **Me** (החשבון שלך) |
   | **Who has access** | **Anyone** |

3. **Deploy**.
4. מעתיקים את **Web app URL**. היא נראית ככה:

```
https://script.google.com/macros/s/AKfycb.....................w/exec
```

> **Who has access חייב להיות Anyone.** אם בוחרים "Anyone with Google account",
> האתר לא יצליח לכתוב. "Anyone" לא אומר שמישהו יכול *לקרוא* את הגיליון —
> הוא רק יכול לשלוח אליו שורה.

## שלב 6 — מדביקים את הכתובת באתר

צריך לערוך את הקבצים בעורך טקסט (Notepad, VS Code — כל אחד).
בכל קובץ מחפשים `SS_SHEETS` ומדביקים את הכתובת בין הגרשיים של `url`:

```js
window.SS_SHEETS = {
  url:    'https://script.google.com/macros/s/AKfycb....../exec',
  secret: ''
};
```

באילו קבצים:

| קובץ | הערה |
|---|---|
| `index.html` | חובה |
| `dashboard.html` | חובה |
| `smartsaver-ai-complete.html` | רק אם משתמשים בגרסת הקובץ היחיד |

> אם עורכים את `index.html` ו-`dashboard.html`, אפשר להריץ
> `python build-single-file.py` והקובץ המאוחד ייבנה מחדש עם הכתובת בפנים.

## שלב 7 — בודקים באמת

1. פותחים את האתר.
2. נרשמים עם אימייל כלשהו.
3. חוזרים לגיליון ומרעננים (F5).

אמורה להופיע שורה חדשה עם `הרשמה`. **זהו.**

## עמודת הסיסמה

בעמודה **סיסמה** מופיעה הסיסמה כפי שהוקלדה, בשורות `הרשמה` ו-`כניסה`.
בשורות אחרות (הפקדה, עדכון יעד) העמודה ריקה — שם לא הוקלדה סיסמה.

### מה זה אומר בפועל

כל מי שיש לו גישה לגיליון רואה את הסיסמאות. זה כולל:

- כל מי שתשתף איתו את הגיליון
- כל מי שרואה את המסך שלך כשהוא פתוח
- כל מי שמגיע לחשבון הגוגל שלך

**לכן:** אל תשתף את הגיליון הזה עם אף אחד שלא חייב, ואל תשאיר אותו פתוח על מסך
שאחרים רואים. אם אתה משתף — שתף את לשונית `Reminders` בלבד, לא את `Log`.

### ההגנה שכן קיימת

באתר עצמו, מתחת לשדה הסיסמה, יש אזהרה קבועה:

> ⚠️ סיסמה חדשה לאתר הזה — לא הסיסמה של האימייל שלכם.

היא שם כי שדה סיסמה שיושב מתחת לשדה "האימייל שלך" מזמין ילדים להקליד את סיסמת
הג'ימייל האמיתית שלהם. **אל תסיר את האזהרה הזו.**

### מה נשמר על המכשיר עצמו

בדפדפן של המשתמש נשמר רק **גיבוב** (PBKDF2, 120,000 סיבובים, מלח אקראי לכל
משתמש) — לא הסיסמה. גם מי שיפתח את ה-localStorage של הילד לא יראה סיסמה.
ההשוואה בכניסה נעשית מול הגיבוב.

### אם מישהו שכח סיסמה

עכשיו אפשר פשוט להסתכל בגיליון ולמצוא את שורת ההרשמה שלו.

## תזכורת שבועית במייל

הדבר היחיד שמחזיר חוסך שבוע אחרי. הסקריפט קורא את היומן, מזהה מי באמצע יעד
ולא הפקיד השבוע, ושולח **רק להם**.

### הפעלה (פעם אחת)

1. בעורך הסקריפטים, בשורה `const SITE_URL = '';` — הדביקו את כתובת האתר.
   (אם האתר עדיין רק על המחשב שלכם, השאירו ריק — המייל יישלח בלי כפתור.)
2. בוחרים בפונקציה **`testReminder`** ולוחצים **Run** — המייל יגיע **אליכם בלבד**.
   ככה רואים איך זה נראה בלי לשלוח לאף אחד.
3. בוחרים **`setupWeeklyReminder`** ולוחצים **Run**. זהו.

התזכורת תרוץ **כל יום ראשון בסביבות 17:00**.

### למי זה נשלח, ולמי לא

| מצב | נשלח? |
|---|---|
| באמצע יעד, לא הפקיד שבוע | ✅ |
| הפקיד בשבוע האחרון | ❌ |
| סיים את היעד | ❌ |
| עוד לא הגדיר יעד | ❌ |
| כבר קיבל תזכורת ב-6 הימים האחרונים | ❌ |

המיילים נשלחים **לכתובת שנרשמו איתה**. כל שליחה נרשמת בלשונית **`Reminders`**
עם סטטוס, כדי שתוכלו לראות מה יצא ומה נכשל.

> **מגבלת גוגל:** חשבון Gmail רגיל שולח עד ~100 מיילים ביום דרך Apps Script.
> לפרויקט בגודל הזה זה הרבה מעבר למספיק.

בתחתית כל מייל יש שורת הסרה ("השיבו במילה הסר") — צריך לטפל בזה ידנית כרגע.

## אם משהו לא עובד

| מה קורה | למה | פתרון |
|---|---|---|
| אין שום שורה בגיליון | הכתובת לא הודבקה, או הודבקה רק בחלק מהקבצים | לוודא ש-`url` מתחיל ב-`https` בכל קובץ שאתה באמת פותח |
| אין שורה, והכתובת נכונה | הפריסה היא `Anyone with Google account` | Deploy ← Manage deployments ← עריכה ← Who has access = **Anyone** |
| פתחתי את הכתובת בדפדפן וקיבלתי JSON | זה תקין | `{"ok":true,...}` אומר שהשרת חי |
| שיניתי את `Code.gs` ושום דבר לא השתנה | פריסה ישנה | Deploy ← Manage deployments ← עיפרון ← Version = **New version** ← Deploy |
| עברית מופיעה שבורה | לא רלוונטי כאן | הסקריפט כותב ישירות לגיליון, בלי קידוד ביניים |

## אם האינטרנט מתנתק

האתר לא מאבד כלום. שורה שלא הצליחה להישלח נשמרת בדפדפן (עד 50 שורות)
ונשלחת אוטומטית בפעם הבאה שהדף נטען או שהחיבור חוזר.

## אם רוצים סיסמה

זה לא חובה. בלי סיסמה, מי שיגלה את הכתובת יוכל להוסיף שורות מזויפות —
הוא לא יוכל לקרוא כלום ולא למחוק כלום.

כדי להוסיף: בוחרים מילה כלשהי וכותבים אותה **בשני המקומות**:

* ב-`Code.gs`: `const SECRET = 'המילה-שלי';`
* בכל קובץ HTML: `secret: 'המילה-שלי'`

אחרי שינוי ב-`Code.gs` צריך לפרוס מחדש (Deploy ← Manage deployments ← New version).

> אם המילה לא זהה בשני הצדדים — שום דבר לא ייכתב.

## מה זה *לא*

הגיליון הוא **יומן פעולות**, לא מקור האמת. האתר עצמו ממשיך לעבוד לגמרי מהדפדפן:
היעד וההתקדמות נשמרים ב-`localStorage`, וכיבוי הגיליון (מחיקת ה-`url`) מחזיר
את האתר בדיוק למצב הקודם, בלי לשבור כלום.

## ביטול

מוחקים את הכתובת: `url: ''`. זהו — האתר מפסיק לשלוח, וגם הטקסט באתר
חוזר לומר שהנתונים נשמרים רק על המכשיר.
