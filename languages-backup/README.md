# גיבוי השפות

האתר צומצם לעברית בלבד (ושקלים בלבד). **שום דבר לא אבד** — כל התשתית הרב־לשונית
שמורה כאן, ואפשר להחזיר אותה.

## מה יש כאן

| קובץ | מה זה |
|---|---|
| `index-multilang.html` | דף הנחיתה **המלא** עם 40 השפות ובורר השפות — עותק מדויק מלפני הצמצום |
| `dashboard-multilang.html` | לוח הבקרה עם עברית/אנגלית/ערבית |
| `i18n.json` | מילון התרגומים — 40 שפות × 225 מפתחות, JSON נקי |
| `languages.json` | רשימת השפות: קוד, שם מקורי, שם באנגלית, האם RTL |

## איך מחזירים הכול

הדרך הבטוחה והמלאה:

```
copy languages-backup\index-multilang.html      ..\index.html
copy languages-backup\dashboard-multilang.html  ..\dashboard.html
```

ואז בונים מחדש את הקובץ המאוחד:

```
python build-single-file.py
```

> שים לב: פעולה זו מחזירה גם את כל שאר הטקסטים לגרסה שהייתה לפני הצמצום.
> אם בינתיים שינית תוכן בעברית — עדיף להחזיר רק את החלקים הרב־לשוניים:
> אובייקט `I18N`, מערך `LANGUAGES`, ה-`<div class="lang-wrap">` בסרגל,
> וה-CSS של `.lang-*`. כולם נמצאים בקבצים כאן.

## מה הוסר מהאתר החי

- בורר השפות בסרגל העליון (הכפתור, החיפוש, רשימת 40 השפות)
- 39 מילוני תרגום — נשאר רק `he`
- מנגנון החלפת סמל המטבע לפי שפה — הכול ₪ קבוע
